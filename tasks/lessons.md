# Lessons

- Keep visible geographic labels within the user's explicitly named scope; do not infer or add a broader location.
- When asked to highlight an area, use a verified boundary polygon instead of connecting unrelated coordinate points or inventing an outline.
- Preserve boundary-data attribution and clearly qualify approximate mapped boundaries.
- When suppressing out-of-scope basemap labels, replace them with verified in-scope locality names so the area remains understandable.
- If a public geodata endpoint is unavailable, use already-rendered map road labels for nearby streets instead of inventing names or presenting them as official area membership.
